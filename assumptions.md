# Assumptions

1. Launch phase is Jabalpur-only and all copy is localized for Jabalpur.
2. NextAuth/OTP production auth will be finalized in next sprint; this build includes role-ready route structure.
3. Razorpay and Cloudinary are represented by integration-ready placeholders for safe local development.
4. COD/manual payment is enabled by default for first launch.
5. Prices are seed defaults and can be edited by admin later.
6. Hindi-English bilingual display is prioritized for high-impact screens and service data.
